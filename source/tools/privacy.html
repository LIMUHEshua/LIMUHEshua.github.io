隐私政策

最后更新日期：2026年3月23日

欢迎使用 LIMUHEshua 的工具服务。我们非常重视您的隐私保护，本隐私政策旨在说明我们如何收集、使用和保护您的个人信息。

1. 信息收集

我们的工具服务遵循以下原则：

  • 本地处理：所有数据处理均在您的浏览器本地完成，我们不会收集或上传您的个人数据
  • 无账户系统：我们不要求用户注册账户，不收集用户名、密码等身份信息
  • 本地存储：部分工具可能使用浏览器的 localStorage 功能在本地保存您的设置和内容，这些数据仅存储在您的设备上

2. 自动收集的信息

当您访问我们的网站时，可能会自动收集以下信息：

  • IP 地址（用于网络安全和访问统计）
  • 浏览器类型和版本
  • 访问时间和日期
  • 访问的页面

这些信息仅用于网站分析和安全保护，不会用于识别个人身份。

3. Cookie 使用

我们的网站使用 Cookie 来改善用户体验：

  • 必要 Cookie：用于网站基本功能的运行
  • 偏好 Cookie：用于记住您的设置和偏好
  • 统计 Cookie：用于了解用户如何使用我们的网站（匿名）

4. 第三方服务

我们的网站可能使用以下第三方服务：

  • GitHub Pages（网站托管）
  • CDN 服务（静态资源加载）

这些服务提供商有自己的隐私政策，我们建议您查看这些政策以了解他们如何处理您的数据。

5. 数据安全

我们采取以下措施保护您的数据安全：

  • 使用 HTTPS 加密传输
  • 不在服务器上存储用户数据
  • 定期审查和更新安全措施

6. 您的权利

根据适用的数据保护法律，您拥有以下权利：

  • 访问您的个人数据
  • 更正不准确的个人数据
  • 删除您的个人数据
  • 限制或反对处理您的个人数据
  • 数据可携带权

7. 政策更新

我们可能会不时更新本隐私政策。任何更改将在本页面上发布，并注明更新日期。建议您定期查看本政策以了解最新信息。
