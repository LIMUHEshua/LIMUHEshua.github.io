### 项目简介

最近开始开发一款Markdown多平台发布工具，旨在解决内容创作者跨平台发布的效率问题。目前已完成前端基础框架搭建。

### 核心功能规划

#### 1. 多平台发布支持
- 微信公众号：富文本HTML生成
- 小红书：纯文本/富文本格式转换
- 知乎：API发布支持

#### 2. AI智能助手
- 标题自动生成
- 内容润色优化
- 敏感词检测
- 自定义Prompt模板

#### 3. 编辑器功能
- Markdown即时渲染
- 代码高亮、表格支持
- 图片拖拽上传
- 多平台预览切换

### 技术选型

| 层级 | 技术栈 |
|------|--------|
| 前端框架 | Vue 3 + TypeScript |
| 构建工具 | Vite |
| UI组件库 | Element Plus |
| 编辑器 | Vditor |
| 状态管理 | Pinia |
| 后端框架 | NestJS（规划中） |
| 数据库 | PostgreSQL（规划中） |
